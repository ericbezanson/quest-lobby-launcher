
# Lunch Quest

A companion app for Quest by Don Eskridge that helps manage game lobbies, player selection, and role distribution.

## Features

- Create and join game lobbies
- Configure optional roles for gameplay
- Generate card setups based on player count
- Randomly select starting player

## Deployment

### GitHub Pages

This project can be deployed to GitHub Pages using the following steps:

1. In your GitHub repository, go to Settings → Pages
2. Set the source branch to the branch you want to deploy (usually `main` or `gh-pages`)
3. Build the project with `npm run build`
4. Push the built files to the deployment branch

The app is configured to work with GitHub Pages' URL structure and handles client-side routing appropriately.
